# Handoff

Start with [CURRENT_STATE](CURRENT_STATE.md), then the
[documentation map](docs/README.md). This file is a pointer, not a second status report.

Before work, inspect the branch, HEAD and working tree and read
[AGENTS](AGENTS.md) and [SOFTWARE_AGENT_INSTRUCTIONS](SOFTWARE_AGENT_INSTRUCTIONS.md).
Select work using [ROADMAP_EXECUTION](ROADMAP_EXECUTION.md) and
[AUTONOMOUS_WORK_QUEUE](AUTONOMOUS_WORK_QUEUE.md), subject to the user's current request.

The [8 September review](docs/product/CRITICAL_REVIEW_2026-09-08.md) distinguishes
current source defects from earlier repaired issues. Review recommendations do
not authorize production writes, outreach, commits or deployments.

The [previous handoff](docs/archive/2026-09-08/HANDOFF.md) is preserved as history.
Its old live counts, next-task instructions and deployment claims are superseded.
